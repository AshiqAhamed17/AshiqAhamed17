### About Me

I work at the intersection of **blockchain security** and **systems engineering** auditing smart contracts, building zero-knowledge protocols, and going deeper into the low-level, performance-oriented engineering that sits underneath both DeFi infrastructure and high-throughput backend systems.

My work so far has centered on **EVM internals, smart contract vulnerability research, and ZK proof systems** (Noir/UltraHonk, Circom, ZoKrates) I've audited 10+ contracts across DeFi protocols, competed in Code4rena and Cantina, and ranked #444 on CodeHawks First Flight. I'm currently expanding that foundation into **distributed systems and low-latency backend engineering**, because I think the next generation of serious blockchain infrastructure and the trading/market-data systems built around it will be won on correctness *and* performance, not one or the other.

 **Core Focus:**
- **Smart Contract Auditing** reentrancy, access control, gas inefficiencies, upgrade-safety, using Foundry, Slither, and Mythril
- **Zero-Knowledge Proofs** privacy-preserving protocols across Noir/UltraHonk and Circom, from circuit design to on-chain verification
- **EVM & Protocol-Level Engineering** Solidity, Huff (gas-level optimization), Rust
- **Systems & Distributed Engineering (active focus)** data pipelines, concurrency, and the performance fundamentals behind low-latency and high-throughput systems

**Currently building toward:**
- A second ZK stack (Circom-based) to complement my Noir/UltraHonk work
- A streaming data pipeline (Kafka/Flink → ClickHouse) to deepen distributed-systems fundamentals
- Deeper Rust concurrency work, extending from my Foundry/protocol experience into systems-level programming
- Continued competitive audits on Code4rena and Sherlock
